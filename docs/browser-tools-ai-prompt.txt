需要迁移三个独立组件：

1. 抓取页面元素
- 点击准星按钮进入选择模式。
- 悬停时高亮元素并显示标签和尺寸。
- 单击后提取 DOM、CSS、选择器、可访问性、附近文本和页面信息。
- 选中后立即复制整理后的上下文，不显示审核弹框。
- 保留审核弹框代码，通过配置开关隐藏。
- 在选区附近显示“已复制”胶囊提示，约 1.5 秒后消失。

2. 注释页面元素
- 选择页面元素后填写评论。
- 支持修复、修改、提问、认可等意图。
- 在对应元素附近显示编号标记。
- 支持删除、清空和复制全部注释。

3. 在截图上绘制
- 获取浏览器当前真实画面。
- 支持画笔、荧光笔、箭头、矩形、椭圆和文字。
- 支持颜色、粗细、撤销、重做和清空。
- 完成后可以复制或下载 PNG。

界面要求：
- 三个按钮放在浏览器地址栏内、刷新按钮之后。
- 顺序为准星、带加号的注释框、画笔。
- 不要做成悬浮在网页右上角的工具条。
- 视觉和交互参考 Orca，并适配目标项目的深色和浅色主题。

外部网站要求：
- 必须支持百度等设置了 X-Frame-Options 或 CSP 的网站。
- 外部网站不能只使用 iframe，Tauri 桌面版必须使用原生子 WebView。
- 通过宿主层向外部页面执行元素选择和注释脚本。
- Windows 使用 WebView2 DevTools 协议获取真实截图。
- 原生 WebView 要跟随内容区域的位置和尺寸。
- 切换页面、标签或卸载组件时必须隐藏或关闭 WebView，不能覆盖其他界面。
- 普通网页预览可以只支持同源页面，但桌面应用必须支持外部网站。

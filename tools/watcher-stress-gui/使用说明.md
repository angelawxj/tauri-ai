# 文件监听压力测试工具

独立 Windows 图形工具，不依赖 Node.js、npm 或 Tauri。双击 `启动测试工具.cmd` 启动。

工具支持高 DPI 显示，不会创建 `.watcher-test`。除“深层目录树”和“跨目录移动”外，测试文件直接生成在所选目录中，不额外创建包装目录，并使用唯一的 `watcher-test-<运行ID>-*` 前缀。运行状态和清理清单保存在 Windows 临时目录；清理时只删除与本次唯一前缀匹配的内容，不删除所选目录或其他文件。

## 测试场景

- 持续追加同一日志
- 自定义目录持续创建文件
- 周期性批量创建多个文件（文件数量表示每批数量，最多500）
- 日志轮转
- 原子保存
- 创建后立即删除
- 瞬时批量创建
- 深层目录树
- 跨目录移动
- 混合场景

## 使用

1. 选择待测试项目目录。
2. 在被测试应用中打开同一个项目。
3. 选择场景和参数并开始。
4. 观察资源管理器刷新范围、选择、展开和滚动位置。
5. 完成后点击“清理测试文件”。
